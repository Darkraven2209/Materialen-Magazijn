# Cruisin Materials Calculator

Een eenvoudige Nederlandstalige materialenverbruik-calculator voor GitHub Pages.

## Inhoud
- 12 materialen met de beginvoorraden uit de aangeleverde afbeelding.
- Vul per materiaal het huidige verbruik in.
- De resterende voorraad wordt automatisch berekend: `basisvoorraad - huidig gebruik`.
- Negatieve restvoorraad wordt rood weergegeven.
- Invoer wordt lokaal in de browser bewaard.
- Resetknop zet alle verbruiken terug op 0.

## Online zetten met GitHub Pages
1. Maak op GitHub een nieuwe repository, bijvoorbeeld `cruisin-materials-calculator`.
2. Upload `index.html` (en eventueel `README.md`) naar de hoofdmap.
3. Open **Settings → Pages**.
4. Kies bij **Build and deployment** voor **Deploy from a branch**.
5. Selecteer branch `main` en map `/ (root)`, en klik **Save**.
6. Na publicatie vind je de website via de Pages-link die GitHub toont.

Er zijn geen extra libraries of buildstappen nodig.
